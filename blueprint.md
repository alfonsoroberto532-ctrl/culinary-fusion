# Culinary Fusion App Blueprint

## Overview

Culinary Fusion is a Flutter application designed to be a definitive culinary guide. It will offer users a rich database of recipes, tutorials, and the ability to create and share their own culinary creations. The app will feature a modern, clean, and intuitive user interface, leveraging Material Design 3 principles, and will be powered by a robust backend using Firebase.

## Project Structure & Features (Current State)

*   **Platform:** Flutter
*   **Styling:** Material Design 3
*   **State Management:** Provider
*   **Routing:** GoRouter (for declarative navigation)
*   **Fonts:** Google Fonts (Oswald, Roboto, Open Sans)
*   **Core Components:**
    *   `lib/main.dart`: Main application entry point.
    *   `pubspec.yaml`: Dependencies managed.
    *   `blueprint.md`: This document.
*   **Authentication:**
    *   Git authentication has been configured to use a Personal Access Token to resolve persistent credential issues.
